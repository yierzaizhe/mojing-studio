MOJING STUDIO

使用帮助

墨境 Studio，本地 PSD / SVG / 图片工作台。浏览源稿图层、调整普通图片，并导出 PNG / JPG。文件在本机处理，导入的源文件保留原样。

打开与切换文件

支持 PSD / PSB、SVG 和常规图片。打开时可以多选，也可以一次拖入多个文件；点击顶部标签切换文档，点击 × 关闭。标签较多时可横向滚动查看。

图层与画布

使用选择工具点击画布中的图形，右侧自动展开并选中对应图层；透明区域会穿透选择。按住 Alt 重复点击，可切换重叠图层。点击眼睛切换显隐，或使用搜索查找图层。

可切换原始合成、图层合成与当前图层预览。拖动画布或按住空格平移，使用缩放按钮查看细节；“画布”可设置工作区背景与透明网格。没有独立画面的节点保留名称与属性。

七款图片滤镜

普通图片打开后，右侧自动进入“调整”。提供自然增强、明亮通透、清晰质感、柔和暖调、冷色清爽、经典黑白和人像柔和七款预设。可继续调节亮度、对比度、饱和度、色温、锐化与滤镜强度。

按住“查看原图”临时对比，点击“恢复默认”清除调整。滤镜仅用于普通图片，PSD 与 SVG 使用图层功能；调整不会改写导入的源图。

PNG / JPG 与文字水印

点击“导出图片”，选择当前画面或选中图层，并设置输出尺寸。PNG 保留透明区域，JPG 可设置背景色。可添加文字水印，调整文字、位置、大小、颜色与不透明度，也支持斜向平铺。

画布快捷操作

PSD 使用文件内的像素缓存预览。复杂特效、调整图层与特殊色彩模式可能与 Photoshop 不同；无像素缓存的图层仍可查看结构与属性。
